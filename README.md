# みんなの家計簿：セットアップ手順

すべて無料でできます。パソコン（Windows / Mac どちらでも）で30分くらいかかります。
使うサービスは2つです。

- **Firebase**（Google）：ログインと、記録の保存・共有を担当
- **GitHub Pages**：アプリを置いて、URLで開けるようにする場所

---

## 1. Firebase のプロジェクトを作る

1. https://console.firebase.google.com を開き、Googleアカウントでログインします。
2. 「プロジェクトを作成」を押し、名前（例：`minna-kakeibo`）を入れて進みます。
3. Googleアナリティクスは「無効」で大丈夫です。
4. 料金プランは最初から無料の「Spark」です。クレジットカードの登録は不要です。

## 2. メールアドレスでのログインを有効にする

1. 左のメニュー「構築」→「Authentication」→「始める」
2. 「Sign-in method」タブで「メール / パスワード」を選び、いちばん上のスイッチをオンにして保存します（「メールリンク」はオフのままで大丈夫です）。
3. 「設定」タブ →「ユーザー アカウントのリンク」はそのままで大丈夫です。
4. 「Templates」タブで、テンプレートの言語を「日本語」にしておくと、パスワード再設定メールが日本語で届きます。

## 3. データベースを作る

1. 左のメニュー「構築」→「Firestore Database」→「データベースを作成」
2. ロケーションは **asia-northeast1（東京）** を選びます。
3. 「本番環境モード」で作成します。
4. 「ルール」タブを開き、中身をすべて消して、このフォルダの **`firestore.rules`** の中身を貼り付けて「公開」します。

このルールが、アプリの安全の中心です。次のことを、サーバー側で必ず守らせます。

- ログインしていない人は、何も読めない・書けない
- 自分の家計簿を追加・修正・削除できるのは本人だけ（友達の家計簿は読むだけ）
- 公開の記録を読めるのは、同じグループに入っていて、持ち主が「見せない」にしていない人だけ
- 非公開の記録・予算・よく使う項目・共有設定は、本人しか読めない
- 「共有しない」にした費目の記録は、公開側に保存できない
- グループには、招待コードを知っている人しか入れない（グループの一覧は誰も取れない）

## 4. アプリの設定をコピーする

1. Firebase のトップ（プロジェクトの概要）で「</>」（ウェブ）のアイコンを押します。
2. アプリの名前（例：`kakeibo`）を入れて「アプリを登録」。Hostingのチェックは不要です。
3. 表示される `firebaseConfig = { apiKey: ..., ... }` の中身を、このフォルダの **`config.js`** の同じ場所に貼り付けて保存します。
   - この値はアプリの住所のようなもので、公開されても問題ありません。守りは手順3のルールが担当します。

## 5. GitHub Pages に置く

1. https://github.com でアカウントを作ります（無料）。
2. 右上の「+」→「New repository」。名前は `kakeibo`、**Public** を選んで「Create repository」。
3. 「uploading an existing file」を押し、このフォルダの中身（`index.html`、`app.js`、`receipt.js`、`config.js`、`sw.js`、`manifest.webmanifest`、`icons` フォルダ）をまとめてドラッグして「Commit changes」。
   - `README.md` と `firestore.rules` は置いても置かなくても大丈夫です。
4. リポジトリの「Settings」→ 左の「Pages」→「Branch」を `main` / `(root)` にして「Save」。
5. 1〜2分待つと `https://（あなたのユーザー名）.github.io/kakeibo/` で開けるようになります。

## 6. Firebase にアプリのURLを登録する

1. Firebase の「Authentication」→「設定」タブ →「承認済みドメイン」→「ドメインを追加」
2. `（あなたのユーザー名）.github.io` を追加します。

## 7. スマホで使う

1. iPhone は Safari、Android は Chrome で、手順5のURLを開きます。
2. ホーム画面に追加します。
   - iPhone：共有ボタン（□に↑）→「ホーム画面に追加」
   - Android：メニュー（︙）→「ホーム画面に追加」
3. ホーム画面のアイコンから開き、「アカウントを作る」で登録します。
4. 「グループを作る」を選び、出てきた招待コードをLINEなどで友達に送ります。
5. 友達も同じURLからアカウントを作り、「招待コードで参加」にコードを入れれば完了です。

機種変更をしたときは、新しいスマホで同じメールアドレスとパスワードでログインすれば、記録もグループもそのまま使えます。

## 画面と使い方

- **ホーム**：上のカードを左右にスワイプすると、自分と友達の家計簿を切り替えられます。友達のカードには「閲覧のみ」と表示され、編集はできません。
- **＋ボタン（下の真ん中）**：記録の入力画面が下から開きます。
  1. 電卓で金額を入れる（「支出／収入」も切り替えられます）
  2. カテゴリを選ぶ。すぐ下の内容（スーパー・外食・朝ごはん…）も選べます
  3. 必要なら日時・支払方法・店舗名・メモを入れる。店舗名は「スタ」と打つと「スターバックス」のように、過去の記録や有名店の候補が出ます
  4. 「友達に公開」のスイッチを決めて「保存」。**記録は最初は非公開です**（共有設定で変えられます）
- **明細**：検索（店舗・メモ・カテゴリ・金額）と絞り込みができます。行を左にスワイプすると編集・削除、タップで詳細。削除した直後は「取り消す」で戻せます。
- **分析**：今月・先月・6か月の切り替え、ドーナツグラフ（タップでカテゴリを強調、明細へ移動）、カテゴリ予算、6か月の推移、月ごとのカレンダー（各日に使った金額）、先月との比較、気づきカード。
- **友達**：友達ごとの今月の公開分の合計と最近の記録、全員の比較、招待、共有設定。
- **画面を上から下に引っ張る**と、最新の情報に更新します。
- **よく使う項目**：入力画面の電卓の上の列です。「＋ 登録」で今の入力を登録しておくと、タップするだけでまとめて入ります。

## 共有設定（メニュー → 共有設定、または友達タブ）

- 新しい記録を最初から公開するか（初期は「しない」）
- 費目ごとの共有：オフにすると、その費目の公開中の記録はすべて非公開に移り、今後も公開できなくなります
- 友達ごとの閲覧許可：オフにした人には、あなたの記録が一切見えなくなります（相手に通知は届きません）
- 共有をすべて解除：公開中の記録をすべて非公開にします
- いちばん上に「友達から見えるもの」のプレビューが出ます

## ログインしたままにする

ログイン画面の「ログインしたままにする」がオン（初期設定）なら、アプリを閉じてもログインしたままになり、次からはすぐに使えます。人と共用の端末では、オフにしてからログインしてください。

## レシートを読み取る

1. ＋ボタンで入力画面を開き、右上のカメラのボタンを押して、レシートを撮影します（写真から選ぶこともできます）。
2. 合計金額・日付・時刻・お店の名前を読み取って入力画面に入れ、お店の名前からカテゴリも選びます。
3. 内容を確かめて「保存」を押します。

- 文字の読み取りはスマホの中で行います。写真はどこにも送られず、保存もされません。
- はじめて使うときだけ、読み取り用のデータ（約2MB）をダウンロードします。
- 読み間違えることもあるので、保存の前に金額を確かめてください。

## PayPay の履歴を取り込む

1. PayPayアプリのホーム →「取引履歴」→ 右上の「取引履歴のダウンロード」
2. 期間を選んで申請し、通知が来たらファイルを保存します（24時間以内）。
3. 家計簿アプリのメニュー（左上の三本線）→「PayPayの履歴を取り込む」でファイルを選びます。
4. 支払いだけにチェックが入った一覧が出るので、カテゴリを確認して「取り込む」を押します（初期は非公開で取り込みます）。

- ファイルはスマホの中で読み取り、保存するのは日付・金額・お店の名前・費目だけです。
- 同じ取引は取引番号で見分けるので、同じファイルを何度選んでも二重には入りません。
- PayPayのパスワードやログイン情報は一切使いません。

## 銀行の自動連携について

銀行の明細を自動で取得する機能は入れていません。銀行から口座の情報を取得するサービスは、銀行法の「電子決済等代行業」にあたり、財務局への登録と銀行ごとの契約が必要なためです。銀行のID・パスワードを預かって代わりにログインする方法は、漏れたときの被害が大きいので採用していません。

## 知っておくこと

- **無料の範囲**：Firebase の無料枠は1日あたり読み込み5万回・書き込み2万回です。友達数人で使うなら、まず超えません。
- **パスワード**：Firebase（Google）が安全な形で保管します。アプリの作者（あなた）を含め、誰もパスワードそのものは見られません。8文字以上で、他のサービスと使い回さないものにしてください。
- **ルールが効いているかの確認**：Firestore の「ルール」タブにある「ルールのプレイグラウンド」で、ログインしていない状態の読み込みが「拒否」になることを確かめられます。
- **アプリを更新したいとき**：GitHub で該当ファイルを上書きアップロードし、`sw.js` の1行目の `kakeibo-v6` を `kakeibo-v7` のように変えると、みんなのアプリにも反映されます。
- **`config.js` を空のまま開くと**：サンプルデータで動くデモ表示になります。見た目の確認に使えます。
